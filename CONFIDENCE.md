## What a self-experiment can actually resolve (n=1, no control group — be honest about the limit)

An n=1 log cannot distinguish "this program worked" from "I'd have grown the same on any program at matched volume/RIR" — there's no counterfactual. It cannot validate or refute a population dose-response curve (the 10–14 set target, the RIR saturation curve, the frequency/split nulls) — those need between-subject or controlled designs, and logbook noise plus scan noise (±3–4 PBF points, `scans/scans.md:7`) swamp any individually-detectable signal at these sample sizes and timeframes. It cannot validate a small pooled effect size (stretch-mediated hypertrophy d≈0.20, `program.md:12`) — the true effect is smaller than one person's measurement noise.

What it genuinely can resolve, cheaply:

| Question | How | What answers it |
|---|---|---|
| Is the RDL 3-week ramp exception right-sized? | Daily 0–10 stiffness score on waking, weeks 1–2, alongside the RDL log | Flat/low early → over-conservative; still elevated late → correctly conservative |
| Does a specific lift cause pain, not just discomfort? | The canary rule already in place (`program.md:180`) — new joint/tendon pain persisting >48h | Direct, unambiguous, no population data needed |
| Is the actual session duration close to the 32–38 min estimate in this specific gym? | `loop.md` check 5, logged wall-clock time | Directly measured, not modeled |
| Is the actual adherence/completion rate what the 4×/week restructure bet on? | `loop.md` check 4, sessions logged vs 4 scheduled | Directly measured — this is the empirical test of weak-link item 11 above |
| Individual load tolerance during the ramp | Reps-at-prescribed-RIR feeling available vs. actual tendon/joint response across weeks 1–4 | This is the entire point of the ramp canary system already built |
