# Grill me — the intake

This repo is a worked example for one specific person, not a program to copy (`PLAYBOOK.md`, "What this is"). Answer these before importing anything — the numbers below are questions, not a form to fill in and forget, because a wrong or missing answer doesn't tune a detail, it invalidates whole sections of `program.md`, `exercises.md`, or `abs.md`. Ordering is by how much of the program a different answer rewrites, not by comfort.

## Tier 1 — answer these before you write a single number

Six, not a rounder number — every one of these, if skipped or answered wrong, breaks a different apparatus wholesale rather than nudging a figure.

| Question | Options | What it rewrites | Already asked? |
|---|---|---|---|
| **Will you log every set — weight, reps, RIR?** | Yes, every session / Inconsistently, compounds only / No | Yes: double progression, per-set RIR, and `loop.md`'s stall-detection checks all run as designed. No: the whole autoregulated-double-progression apparatus doesn't apply — you need a cruder calendar-based scheme, closer to the scheduled-deload approach `program.md` already found inferior in an RCT (`program.md:184-188`), accepted only because no tracking is worse. | PLAYBOOK row 7 |
| **Will you weigh in every morning and log it, under fixed conditions?** | Yes / Sometimes / No | Gates the entire nutrition calibration loop (`CLAUDE.md:15`: daily weigh-in → weekly average → >0.5 lb/wk gain −150 kcal, flat +150), and `loop.md` check 6. | **What equipment do you have, and how crowded is it at your usual time?** | Busy commercial gym / Quiet gym / Home barbell + rack + dumbbells / Minimal (bands/bodyweight) / Machines-only | Busy commercial: `program.md`'s 13-exercise list and fixed-substitute table (`program.md:122-136`) transfer close to as-is. Recomp: only evidenced as realistic for novices/detrained/higher-bodyfat lifters (Barakat 2020, `abs.md:84`) — whether it's real or false hope depends on the training-age answer below. Maintain: volume could trim toward the 4-set floor instead of holding the 10–14 target for growth. | PLAYBOOK row 5 |

## Tier 2 — answer these and the numbers fit properly

The program still runs without these; they resize a ramp, a BMR seed, a risk assessment, or a protein ceiling rather than determining whether a section exists at all.

| Question | Options | What it resizes | Already asked? |
|---|---|---|---|
| **Training history — true novice, no real gap, gap with data, or gap with only memory of it?** | Novice / No gap / Gap + scan/log spanning it / Gap, memory only | This repo's own worked example of "distrust self-report" (`PLAYBOOK.md:71-75`): the stated "~1 year off" was overridden by InBody SMM rising 75.2→76.5 lb, collapsing the ramp from a beginner-reintro to 1 week (RDL 3, `program.md:160-176`). No scan: fall back to Mifflin-St Jeor off bodyweight, and `abs.md:97`'s skinfold-mm tracking becomes the primary body-comp signal instead of any BIA trend. | PLAYBOOK row 1 |
| **Any other regular cardio/sport — running, swimming, cycling, court sports?** | None / Swimming / Running / Cycling / Court sport | `swimming.md`'s whole zero-lower-body-interference verdict is modality-specific: the interference mechanism is eccentric muscle damage (Wilson 2012), which running causes and swimming/cycling don't. Applying the swimming verdict to a runner is the exact unwarranted cross-method transfer `PLAYBOOK.md` rules 1–2 warn against — running needs its own dose-threshold check, not this repo's answer. | **NEW** — implicit in `swimming.md`'s framing, never asked as an intake question |
| **Any kidney, liver, or metabolic condition — or reason to suspect one?** | None / Diagnosed condition / Unsure | Gates the protein ceiling only (`CLAUDE.md:7` flags "no known issues" as assumed, not cleared). No condition: 120–155 g/day (build) or 130–190 g/day (cut) apply as stated. Diagnosed: neither range applies without medical clearance — Morton 2018's plateau reasoning assumes normal renal clearance. Unsure: default to the lower bound. Narrow blast radius — this changes one number, not a section. | PLAYBOOK row 6 |

## What we don't ask, and why

| Refused question | Why | Points at |
|---|---|---|
| Goal body-fat % / target for visible abs | No peer-reviewed study establishes a body-fat threshold for visible abs — both the ruler (BIA/DEXA, 15–20 point limits of agreement) and the folk "10%" figure carry error bars wider than the gap between them. Malformed question, not a hard one. | `abs.md` |
| Goal weight | Fat mass is computed as weight minus LBM — a residual of two big, individually noisy numbers. A target weight with no body-comp method behind it is a derived number mistaken for an absolute. | `scans/scans.md:7` |
| 1RM test | The program's progression scheme is rep-zone double progression, RCT-matched or ahead of percentage-based programming (PMID 36515591) — a different programming style than 1RM testing serves. Also actively contraindicated during the ramp, whose entire point is protecting tendons before near-maximal loading. | `program.md:154-158`, `program.md:160-182` |
| Somatotype (ecto/meso/endomorph) | No source across any of this repo's evidence sweeps cites somatotype as predicting any hypertrophy-driving variable. Undefined folk taxonomy, same category error as the "10% for abs" claim. | `exercises.md`, `abs.md` |
| Current daily calorie intake / run a TDEE calculator | "TDEE is unknown to ±300 kcal by any formula" — handwritten or app math hides double-counts and undercounts. Seed from BMR, calibrate against measured trend; a calculator's output is never the target itself. | `CLAUDE.md:14-15`, `PLAYBOOK.md` step 3 |
| Preferred split (PPL, bro-split, upper/lower) | Split choice has no difference at equated volume (2024 meta, 14 studies). This is the single most personal, least evidence-constrained decision in the plan — Tier 1's time-budget question determines the split by arithmetic, not preference. | `program.md:19`, `PLAYBOOK.md:131` |
| Motivation, 1–10 | Self-rated motivation predicts nothing in this repo's evidence base. Concrete, checkable things instead: setup cost, station contention, skill demand, stated past-failure patterns (Tier 3, adherence-failure question). | `exercises.md` |

## If you answer nothing

Starting with zero answers means importing one specific person's constraints wholesale — busy commercial gym, logs everything, weighs in daily, no flagged injuries, goal is build-at-near-maintenance, training history confirmed non-detrained by scan data, has an InBody baseline, no other cardio, no kidney/metabolic flags, male — which is exactly what `PLAYBOOK.md` opens by warning against copying. If you must start today: run the 1-week universal ramp (RDL exception 3 weeks, `program.md:160-182`) at RIR 4, log what you can, and correct the plan as real answers arrive. Starting imperfectly beats not starting; it doesn't beat answering Tier 1 first.
